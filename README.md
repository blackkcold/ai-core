# AI Core

A lightweight, reusable provider registry, model catalog, search toolkit and optional HTTP/MCP gateway for independent applications.

**Status:** first release in development. Source code is committed incrementally; API and deployment are not production-verified until CI passes.

## Delivery scope

1. Versioned provider/model catalog and setup-code generator
2. Tavily, Firecrawl, TinyFish, Exa, Parallel and Brave search adapters
3. Quota/budget guards, evidence normalization, caching and safe fetch
4. Optional HTTP gateway, native model adapters and MCP server
5. TypeScript/Python/Swift examples, tests, CI and release notes

Default mode is local-only; no credential is included in the repository.
